# 三字词语序数据集

用于训练**三字词乱序还原**模型的数据集：给定三个打乱的汉字，输出正确的中文词。

```
输入：决 定 性（乱序）
输出：决定性
```

## 数据构成

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| `three_char_words.txt` | 三字词表（LCCC 语料验证 + 极验真实词） | 29,366 词 |
| `order_dataset/train.jsonl` | 训练集 | 23,783 条 |
| `order_dataset/val.jsonl` | 验证集 | 4,196 条 |
| `order_dataset/stats.json` | 统计信息 | — |

### 词表来源

| 来源 | 词数 | 说明 |
| --- | --- | --- |
| jieba 三字词，**在 LCCC 语料中出现过** | 27,004 | 真实使用过的词 |
| 极验验证码真实词 | 1,454 | 从 word 型 ques 图 OCR 得到 |
| **去重合计** | **28,256** | 用于构造排序数据集 |

### 为什么不用 jieba 全部 13 万词

jieba 词典里有 131,321 个三字词，但质量参差：

| 词表 | 词数 | 例子 |
| --- | --- | --- |
| jieba 全部 | 131,321 | 一一例、一万万、一二九 |
| 词频≥100 | 5,321 | 一万两、一二九 |
| **在 LCCC 851 万行语料中出现过** | **28,249** | 长辛店、双流县、格兰仕、翡翠谷 |

**只有 21.5% 的 jieba 三字词在真实语料中出现过。**

用真实语料验证后，词表从 6,419（词频≥100）扩到 28,256，
分类器 Top-1 从 65.5% 提升到 73.1%。

**教训：词频不等于词的真实性。**

## JSONL 格式

每行一个字符集（同一组三个字）：

```json
{
  "chars": ["定", "性", "决"],
  "cands": ["决定性", "定决性", "性决定", "性定决", "决性定", "决定性"],
  "answers": ["决定性"],
  "ambiguous": false
}
```

| 字段 | 说明 |
| --- | --- |
| `chars` | 排序后的字符集（同一组三个字） |
| `cands` | 全部排列（通常 6 种，有重复字时更少） |
| `answers` | **合法答案**（通常 1 个） |
| `ambiguous` | 是否存在多个合法答案 |

### 多解处理

同一组三个字可能有多个合法排列，实测有 **25 组**：

```
三十岁 / 十三岁
三十年 / 十三年
不久前 / 前不久
不得了 / 了不得
不由得 / 由不得
金包银 / 银包金
```

这些标记为 `ambiguous: true`，训练时跳过，评估时单独统计。
**不能强行只标一个答案** —— 否则会把合法词当负样本。

## 数据划分

**按字符集划分，不按词划分。**

```
训练 23,783 个字符集
验证   4,196 个字符集
```

同一组三个字的全部排列必须**全在同一侧**，否则评估失真。

实测按词划分会产生泄漏：`桂油肉` 在训练集、`肉桂油` 在验证集，
两者是同一组字符集的不同排列。

## 质量过滤

jieba 词典里有大量不适合的词，已过滤：

| 过滤规则 | 例子 |
| --- | --- |
| 纯数字组合 | 一二三、一万万 |
| 「第」开头 | 第一次（保留，是实义词） |
| 「一」开头虚词 | 一一例、一下场、一丛丛 |
| 含字母数字 | A股、B超 |
| 词频 < 100 | 生僻组合 |

过滤前后对比：

```
词频≥3：102,883 词（大量「一一例」这类垃圾）
词频≥100：5,321 词（天安门、委员会、武汉市、计算机）
```

## 实测结果

在极验验证码的 292 个真实答案上：

在 47 个「字符集完全未出现在训练集」的词上（**零泄漏**）：

| 方案 | Top-1 | Top-3 |
| --- | --- | --- |
| 字符 3-gram | 85.1% | 95.7% |
| 六选一分类器 | 80.9% | 97.9% |
| **融合（权重 0.4）** | **89.4%** | **100.0%** |

**融合比纯 n-gram 提升 4.3 个百分点，Top-3 达到 100%。**

端到端（292 张真实验证码）：77.1% → 81.5%。

### 训练建议

```python
# 分类器：6 层 Transformer，dim=192，词表 8192，685 万参数
# 训练：23,783 词，6000 步，batch 32，lr 3e-4
# 实测 Top-1 73.1%（单独用），融合后 89.4%
```

注意：冻结 backbone（只训分类头）反而更差（60.8%）。
参数/数据比约 290:1，已经接近过拟合边界，再加数据才能继续提升。
